# 10xapply

10xapply applies to LinkedIn jobs from users' own LinkedIn accounts. It receives job matches from 10xjobs by webhook, lets each user approve them, and runs the applications through the user's own LinkedIn session, carefully and at a human pace.

It is a private experiment, kept separate from 10xjobs. See [CLAUDE.md](CLAUDE.md) for what it is, the decisions so far and how work is done here.
